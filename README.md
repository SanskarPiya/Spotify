# 🎵 Spotify Clone

A frontend clone of Spotify built entirely with **HTML**, **CSS**, **EJS** , **Node.JS** and **Express.JS**.

## 📱 Responsive Breakpoints

| Breakpoint        | Changes                                               |
| ----------------- | ----------------------------------------------------- |
| `< 1100px`        | Hides forward navigation and some controls            |
| `< 800px`         | Smaller artist images; music player stacks vertically |
| `< 615px`         | Sidebar hidden; artist cards shrink to 120px          |
| `< 700px` (login) | Full-width card; inputs and button span 100%          |
